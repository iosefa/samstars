# Reference Dataset Data Card

## Reference dataset definition

Reference crowns are the union of all `crowns.gpkg` geometries in `v2/train-sam`. Each crown polygon carries a numeric species label in the `class` field (EPSG:6635). This combined geometry+label set is the authoritative reference dataset for training/validation.

Plot tiles were selected along precipitation and elevation gradients to capture the major species composition.

## Split design (current run)

- Fixed validation chips are read from `v2/chip_splits_128_100/fixed_val_manifest.json` (10 chips; tiles: tile-000, tile-001, tile-005, tile-006, tile-008).
- The fixed validation set is selected **randomly at the chip level** (not spatially stratified), using a shuffled chip list (seeded in `build_chip_splits.py`) and taking chips until a target crown count is reached (if `--fixed-val-crowns` was used). Training chips are all remaining chips.
- Per-size training subsets are **nested** and ordered by ascending crowns-per-chip (`--order-by instances-asc`).
