# Pipelines

Entry points for model training and inference.

Subfolders:
- `sam/`: SAM decoder training + SAM inference on chips.
- `stardist/`: StarDist training/evaluation on SAM outputs.
- `detectron/`: Detectron2 instance segmentation baselines.
- `detectron_mc/`: Detectron2 segmentation + classification.
- `objects/`: object feature extraction + XGB classification.
- `shared/`: shared helpers (scaling).
