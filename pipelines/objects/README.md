# Object Features + Classification

- `create_objects_from_detectron_sizes.py`: reference objects with class labels.
- `create_objects_from_detectron_eval_sizes.py`: objects from detectron outputs.
- `create_objects_from_stardist_eval_sizes.py`: objects from stardist outputs.
- `classify_objects_from_sizes.py`: XGBoost classifier on object features.
- `make_pred_gpkgs_classified.py`: attach predicted classes to polygons.
